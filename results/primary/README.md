# 수능·회계사 예비 분석 (2026-11-26 갱신)

## 실행 방법

저장소 루트에서 `python src/preprocess/check_primary.py`, `python src/analysis/analyze_primary.py`를 차례로 실행한다. Python 표준 라이브러리만 사용한다. 입력은 PR #4의 정제 자료(`data/processed/primary/`)이며, 이번 계산에 사용한 #4 커밋은 `45f208095b8a414b149ec5effb1f38336cc25f26`이다. #4가 main에 반영되기 전에는 해당 커밋의 입력을 별도 작업 디렉터리에 준비해야 한다.

- 수능 영어 2017–2025년, 한국사 2016–2025년, 회계사 1차 2016–2024년. 회계사 2019년은 사용자가 직접 확보한 금융감독원 보도자료 3쪽을 대조하여 포함했다. 회계사 2025년은 배점·과목 변경으로 별도 관찰한다.
- 공통 비교는 2020–2022년 대 2023–2024년이다. 전체 과거(2022년까지 확보한 동일 체계)도 별도로 비교하고, 수능은 최근을 2023–2025년으로 확장한 두 비교를 추가한다. 매년 동일 가중치를 부여한다.
- 수능의 대표 지표는 영어 90점 이상, 한국사 40점 이상(1등급)이다. 1–2등급 합계는 보조 지표로 사용한다. 회계사 대표 지표는 80점 이상 비율, 보조 지표는 70·90점 이상이다. 80점은 공식 상위등급 경계가 아니며, 공식 전과목 평균 분포는 과목별 결과와 별도로 해석한다.
- 전년 대비 변화는 실제 1년 간격의 자료만 사용한다. 과거(2022년까지)의 최소·최대 변화와 최대 절대변동을 구분한다. 전체 분포 변화량(TVD)은 구간별 비율 차이 절댓값 합의 절반이며, 연간 TVD를 과거 최대값과 비교한다. 이는 통계적 유의성 검정이 아니다.

## 검증과 해석

#4의 세 입력 CSV(`csat.csv`, `cpa.csv`, `denominators.csv`)와 Git blob SHA-1이 일치하는 로컬 입력으로 분석 코드를 두 번 실행했다. 두 실행의 결과 CSV 10개가 바이트 단위로 일치했다. 인원 합, 누계, 분모, 구간 경계 및 분포 비율 차이 합을 검산한다.

공통 기간 비교에서는 수능·회계사 7과목 중 6과목의 대표 고득점 비율이 감소했다. 회계사 2019년 추가로 전체 과거 기준과 과거 변동 폭의 결과는 갱신됐지만, 공통 기간 결과는 바뀌지 않았다. 수능의 2025년 포함 결과는 별도 비교 행을 사용한다.

이 분석은 수능·회계사에 한정된다. 다른 시험은 자료 통합 후 별도로 분석한다. 난도, 응시자 구성, 학습 환경, 시험 제도 등의 영향을 분리하지 못하므로 점수 변화로 AI 부정행위나 인과관계를 판정할 수 없다. 시각화는 이 PR의 범위에 포함하지 않는다.
