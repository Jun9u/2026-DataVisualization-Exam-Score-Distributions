# 수능·회계사 예비 분석 (11월 20일)

실행: Python 3.12, 표준 라이브러리만 사용. 저장소 루트에서 `python src/preprocess/check_primary.py`, `python src/analysis/analyze_primary.py` 순서로 실행함. `data/processed/primary/` 입력이 필요함. 분석 스크립트는 기존 11월 20일 코드를 공개용 선정 입력과 상대경로에 맞게 수정한 버전임. 2019 제외된 원자료 및 다른 시험의 원자료는 공개 입력에 포함하지 않으므로 `01_exclusions.csv` 대신 자료 선정 기록을 참조함.

- 시행연도 기준, 최근 2023–2024년 / 고정 과거 2020–2022년 / 전체 과거 2022년까지의 검증분. 연도별 동일 가중치. 전년차는 정확히 한 해 차이인 쌍만 사용.
- 수능 1등급: 영어 90점, 한국사 40점 이상. 1–2등급 보조. 회계사 80점 이상 대표(공식 상위등급 아님), 70·90점 이상 보조. 전과목 평균은 별도 보조 지표. 2025 회계사는 개편 후 별도, 수능 2025는 추가 관찰.
- 과거 연간 차이의 최솟값·최댓값과 최대 절대변동을 구분. 전체 분포 변화는 구간 비중 절대차의 합/2(%p)로 기술함. 이 결과만으로 부정행위 원인이나 통계적 유의성을 판단하지 않음.

`02_annual.csv`, `02_recent_vs_history.csv`, `03_periods.csv`, `04_distribution.csv`, `04_band_changes.csv`, `04_distribution_summary.csv`, `05_cpa2025_*.csv`는 계산 결과. `01_audit.csv`는 공개용 입력의 검산 기록. 시각화 및 추가 시험 분석은 후속 작업.

고정 과거 대비 최근 대표 고득점 비중은 수능·회계사 7과목 중 6과목에서 감소. 회계학은 2023년 0.18%, 2024년 11.32%로 큰 변동을 보임. 이 결론은 두 시험의 선정 지표에 한정하며 전체 시험의 일반적 변화로 해석하지 않음.
