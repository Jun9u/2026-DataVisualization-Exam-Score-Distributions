# 분석 자료 선정

기준일: 2026-11-24. [연구 및 분석 계획](research_plan.md)에 정의한 질문·지표·기간 조건을 적용함(선행 PR [#7](https://github.com/Jun9u/2026-DataVisualization-Exam-Score-Distributions/pull/7)). 11월 23일 원검토 결과를 보존하면서 선정 여부를 다시 판정함. 성적 증감 방향을 선정 기준으로 사용하지 않음.

## 1. 어떤 자료를 왜 선정하는가

목표는 2023년을 전후로 **같은 시험에서 점수 수준, 고득점 비중, 분포 모양이 어떻게 변했는지** 확인하는 것임. 전체 점수분포가 없는 시험은 평균·과락률·표준편차로 해당 질문만 보완함.

| 판정 절차 | 통과 조건 | 미충족 시 |
| --- | --- | --- |
| 지표 관련성 | 평균, 점수구간별 비율, 과락률, 표준편차 등 성적 변화를 직접 설명할 값 | 응시·합격자 수 및 선발 합격선만 있으면 배경용 |
| 수치 신뢰성 | 공식 원문 또는 발행기관 대조 사본, 구간·응시자·집계대상·수치 확인 | 원출처/수치 검증 보류 |
| 비교 가능성 | 동일 점수 정의, 과목, 체계 및 집단 기준으로 비교 가능 | 개편 전후 분리; 정의 불일치 해소 전 보류 |
| 기간 | 2023년 이전과 이후에 각각 비교 가능한 관측이 있는지 | 아래 분석 수준 구분 |

기본 조사 범위는 2016–2025년. 모든 시험에 이 기간의 자료가 있다는 뜻은 아님. 실제 사용 기간은 점수 체계가 같은 구간과 검증 완료 연도만 교집합으로 결정함. 원문을 못 찾은 연도는 '미확보', 찾았지만 대조가 안 된 연도는 '검증 보류', 개편 이전·이후는 '별도 체계'로 구분함. 기간을 맞추려고 결측치를 채우지 않음.

| 분석 수준 | 조건 | 결과 활용 |
| --- | --- | --- |
| L1 장기 | 과거 5개년 이상, 최근 2개년 이상, 검증된 과거 연속 전년차 4개 이상 | 전후 변화와 과거 변동 폭 비교 |
| L2 보조 | 동일 지표로 양측 2개년 이상, L1 미충족 또는 회차·전년쌍 정의 미확정 | 실제 확보분의 기술 비교만 |
| L3 제한 | 한쪽 기간 2개년 미만 또는 개편 후 단년 | 단면/최근 참고, 전후 종합 제외 |
| P 보류 | 원문·수치·정의 미확인 또는 검증 미완료 | 해결 후 재판정 |
| X 부적합 | 지표·집단이 연구 질문에 직접 답하지 못함 | 성적 비교 제외 |

L1·L2는 선정하고, L3·P·X는 선정하지 않음. L2에서 비교 자체의 정의가 확인되지 않았다면 P로 둠. L1은 숫자상 연도 수만으로 자동 확정하지 않고 같은 체계로 비교 가능한 연속쌍을 확인함. L1/L2는 분석 범위이지 결과의 크기나 중요도를 평가한 순위가 아님.

모든 88개 ID의 기간과 미선정 이유는 아래 요약 CSV에서 확인 가능함. '미선정'은 자료가 존재하지 않거나 품질이 나쁘다는 뜻이 아님. 미선정 중 조건을 해결할 수 있는 자료는 같은 기준으로 다시 판정하며, 현재 연구 질문·기간이 맞지 않는 자료를 억지로 포함하지 않음.
