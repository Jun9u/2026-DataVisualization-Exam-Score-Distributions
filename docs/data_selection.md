# 분석 자료 선정

기준일: 2026-11-24. [연구 및 분석 계획](research_plan.md)(선행 PR [#7](https://github.com/Jun9u/2026-DataVisualization-Exam-Score-Distributions/pull/7))에 따라 11월 23일 검토 결과를 다시 판정했다. 관측된 성적의 상승·하락 방향은 선정 기준으로 삼지 않는다. 어떤 시험에서 어떤 지표를 분석할 수 있는지는 [지표별 자료 현황](indicator_coverage.md)에서 확인할 수 있다.

## 1. 어떤 자료를 왜 선정하는가

목표는 2023년을 전후로 **같은 시험에서 성적 수준, 고득점 비율, 점수분포가 어떻게 변했는지** 확인하는 것이다. 전체 분포를 확보하지 못한 시험은 평균·과락률·표준편차로 확인할 수 있는 범위만 분석한다.

| 판정 절차 | 통과 조건 | 미충족 시 |
| --- | --- | --- |
| 지표 관련성 | 평균, 점수구간별 비율, 과락률, 표준편차 등 성적 변화를 직접 설명할 값 | 응시·합격자 수 및 선발 합격선만 있으면 배경용 |
| 수치 신뢰성 | 공식 원문 또는 발행기관 대조 사본, 구간·응시자·집계대상·수치 확인 | 원출처/수치 검증 보류 |
| 비교 가능성 | 동일 점수 정의, 과목, 체계 및 집단 기준으로 비교 가능 | 개편 전후 분리; 정의 불일치 해소 전 보류 |
| 기간 | 2023년 이전과 이후에 각각 비교 가능한 관측이 있는지 | 아래 분석 수준 구분 |

기본 조사 범위는 2016–2025년이다. 그러나 모든 시험에서 10년치 자료를 확보한 것은 아니다. 점수 체계가 동일하고 자료 검증을 마친 연도만 사용한다. 원문이나 필요한 수치를 이번 조사에서 확보하지 못한 연도는 '미확보', 원문은 찾았지만 대조가 끝나지 않은 연도는 '검증 보류'로 구분한다. 시험이 개편되었다면 개편 전후를 나누고, 자료가 없는 해는 임의로 채우지 않는다.

**미확보는 자료가 없거나 확보할 수 없다는 뜻이 아니다.** 예를 들어 첨부파일 다운로드 오류(HTTP 503), 필요한 과거 표를 찾지 못한 경우, 성적표는 확인했지만 필요한 지표를 읽지 못한 경우가 모두 포함된다. 실제 접근 실패와 지표 미확보는 상세표와 출처 목록에 기록한다. 시험 미시행이나 자료 비공개가 확인된 경우에만 그 사실을 별도로 명시한다.

| 분석 수준 | 조건 | 결과 활용 |
| --- | --- | --- |
| L1 장기 | 과거 5개년 이상, 최근 2개년 이상, 검증된 과거 연속 전년차 4개 이상 | 전후 변화 및 과거 변동 폭 비교 |
| L2 보조 | 동일 지표로 양측 2개년 이상, L1 미충족 또는 회차·전년쌍 정의 미확정 | 확보한 기간의 차이 비교 |
| L3 제한 | 한쪽 기간 2개년 미만 또는 개편 후 단년 | 단면/최근 참고, 전후 종합 제외 |
| P 보류 | 원문·수치·정의 미확인 또는 검증 미완료 | 이번 분석에서 제외; 조건 충족 시 재검토 가능 |
| X 부적합 | 연구 질문에 맞지 않는 지표 또는 집단 | 성적 비교 제외 |

장기 비교(L1)와 보조 비교(L2)에 해당하는 자료를 선정한다. 제한 관찰(L3), 보류(P), 부적합(X) 자료는 전후 종합 분석에 포함하지 않는다. 두 기간의 점수나 집계 대상이 서로 비교 가능한지 확인하지 못했다면 보조 비교가 아니라 보류로 분류한다. 장기 비교에는 실제로 같은 시험 체계에서 1년 간격으로 비교할 수 있는 과거 자료가 최소 네 쌍 필요하다. L1과 L2는 자료의 우열이 아니라 가능한 분석 범위를 나타낸다.

선정한 시험에서도 사용하지 않는 연도와 지표는 동일하게 제외한다. 예를 들어 회계사 2019년, 학력평가 2018·2021·2024년, LEET 2021년을 보완하기 위한 추가 자료 수집은 현재 계획에 없다. 회계사 2025년처럼 개편 후 이미 확보한 자료는 별도 참고 결과로만 제시할 수 있다.

남은 데이터 작업은 **선정 자료의 정제·검산 및 분석에 필요한 보완**이다. 주택관리사보 2차 입력 추가, 선정 자료의 수치·정의와 출처 확인 등이 여기에 해당한다. 필수 검증에서 문제가 발견되면 해당 지표를 수정하거나 사용 범위를 줄인다. 미선정 자료의 확대는 이번 분석에 포함하지 않으며, 별도 후속 연구에서 검증 조건이 해결될 때 재검토할 수 있다.

88개 항목 전체의 제외·선정 결정은 [시험별 선정 요약](../data/metadata/exam_selection_summary.csv)에 기록했다. 표의 '추후_재검토_조건'은 현재 수행할 작업이 아니라 향후 해당 자료를 사용하려면 충족해야 하는 조건이다.

분야별 CSV 네 개를 두 통합표로 교체했다. 기존 분야 구분은 '분류' 열에, 기존 검토 내용과 근거는 원검토 관련 열에 보존했다. TOEIC의 기존 지표명 '공표 원점수 평균'도 원본 열에 보존하고, 실제 분석 지표는 '공식 환산점수 연평균'으로 수정했다. 원자료 근거 열에 기재한 상대경로는 **11월 23일에 보존한 자료 묶음의 내부 위치**다. 공개 저장소에 해당 원문이 있다는 뜻은 아니다. 원문별 상세 출처 및 조회 기록은 위 출처 목록을 참조한다. 정제 데이터의 출처는 PR [#2](https://github.com/Jun9u/2026-DataVisualization-Exam-Score-Distributions/pull/2), [#4](https://github.com/Jun9u/2026-DataVisualization-Exam-Score-Distributions/pull/4), [#5](https://github.com/Jun9u/2026-DataVisualization-Exam-Score-Distributions/pull/5)의 출처표와 README에서 확인할 수 있다.

기존 88개 조사 항목과 425개 검토 행, 기존 선정 11개 항목이 유지되었는지 확인했다. 통합표의 열 수, 고유 ID 수, 분석 수준별 행 수, 신규 선정 EX-018도 대조했다. '과거_달력연속쌍수'는 시행연도 목록에서 1년 간격으로 이어지는 연도 쌍의 개수로, 실제 비교 가능한 쌍의 개수와는 구분한다. 장기 비교 판정에는 기존 검토의 비교 가능 기록을 함께 사용했다. 이번 변경은 분석 계획과 자료 선정에 관한 것으로 새로운 원자료 추출, 통계 분석, 보고서 변경은 포함하지 않는다.

파일명은 프로젝트에서 직접 작성하는 문서·CSV·코드에 소문자와 언더바를 사용하는 `snake_case`로 통일한다. `README.md`, `.gitignore` 등 도구와 GitHub의 관례적인 파일명은 유지한다. 브랜치명은 파일명 규칙과 별개다.
