# 국내 주요 시험의 성적 분포

세종대학교 데이터시각화 기말 프로젝트 (2026년 2학기)

AI 부정행위 논란을 계기로 최근 시험의 성적 수준과 분포가 과거에 비해 어떻게 달라졌는지 분석함. 특정 시험·과목·점수대의 변화에 주목하며, 성적 통계만으로 부정행위 여부나 원인을 판단하지 않음.

## 분석 범위

시행연도 2016–2025년을 기본 범위로 설정. 2023년을 기술적 비교 경계로 두되, 부정행위 발생 시점으로 해석하지 않음.

| 시험 | 지표 |
| --- | --- |
| 수능 영어·한국사 | 9등급 분포, 1등급 비중 |
| 공인회계사 1차 | 10점 구간 분포, 80점 이상 비중 |
| 고3 7월 전국연합학력평가 | 영어·한국사 등급 분포 |
| LEET | 표준점수 구간 분포 |
| 주택관리사보 1차, 세무사 1·2차, 관세사 1·2차 | 과목별 평균·과락률 |
| TOEIC | 공식 연평균 |
| 영양사 | 회차별 평균·표준편차 |

시험별 점수체계와 응시집단을 구분하여 비교. 누락 연도를 임의 보간하지 않으며 제도 개편 전후는 분리함.
