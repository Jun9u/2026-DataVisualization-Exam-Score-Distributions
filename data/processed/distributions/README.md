- 고3 7월 전국연합학력평가 영어·한국사: 검증된 7개년(2017·2019·2020·2022–2025), 126개 등급 행. 2024년은 11월 26일 사용자가 서울교육청 자료실에서 직접 받은 연간 ZIP 내부 인천교육청 XLS로 검증했다. 기존 재배포 XLS와 SHA-256 및 18개 등급 행이 일치한다. 2018·2021년은 별도 보완 조사 결과가 보고되었으나 이 PR에는 아직 반영하지 않았다. 2026 제외. 같은 월·학년끼리 비교하고 수능과 모집단이 겹침을 고려함. `과목응시자`는 과목별 N, `구분점수`는 실제 등급표의 원점수 경계임.
- LEET: 2019·2020·2022–2025 언어이해·추리논증 표준점수 5점 구간. 2021 미확보. 2018은 이전 점수체계로 별도 표시함. 표준점수 분포로 원점수 평균 상승을 판단하지 않음. 공표비율의 반올림 차이는 2024 언어 70–75점, 2025 추리 55–60점에서 확인됨. 분석 비율은 인원/과목유효성적자로 재계산함. 하한 포함, 상한 미포함.
- 출처 파일은 직접 확인한 URL, 원자료 경로, SHA-256. `july_sources.csv`의 기존 수집·검증 기준일은 2026-11-23 KST이며, 2024년 원표는 2026-11-26 KST에 사용자가 확보했다. 출처 URL은 연간 ZIP 게시 목록(게시글 1544)이다.
