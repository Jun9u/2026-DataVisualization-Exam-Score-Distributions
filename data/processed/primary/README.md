# 수능·공인회계사 1차 정제 입력

11월 20일 검증 묶음에서 본분석에 필요한 수치만 추출함. 모든 연도는 실제 시행연도. 원문 PDF/HWP/이미지는 공개 저장소에서 제외함. 출처 CSV의 URL·해시·자료명·표 위치를 사용하여 원문을 대조할 수 있음. 배포 사본과 발행기관의 원문은 출처형태/URL로 구분함. 공표 자료의 재배포 권한을 일괄 부여하는 것은 아님.

- `csat.csv`: 재생성한 171개 등급 행, 영어 2017–2025년·한국사 2016–2025년. 2020 한국사 9등급 공표비율은 0.13%, 인원 564명으로 원문 수정 반영. 계산에는 인원·분모 사용.
- `cpa.csv`: 540개 구간, 5과목 및 공식 전과목 평균. 2019 전재 원표 미대조로 제외, 2025 과목·배점 변경 후 별도. `하한이상_누적인원`의 차이를 `구간인원`으로 사용. 마지막 구간은 90점 이상(100점 이하).
- `denominators.csv`: 수능의 별도 발표 과목별 응시자 수.
- `*_sources.csv`: 원자료 URL, 상대경로 및 SHA-256. 수능 수집일 2026-11-19, CPA는 11월 19–20일 검증 묶음에 보존된 출처를 사용.

출처를 포함한 원자료→정제표 재생성은 로컬 11월 20일 보존 ZIP의 `code/rebuild_csat.py`, `inputs/cpa/build.py`를 사용함. HWP/PDF 판독에는 olefile 0.47 및 Poppler pdftotext 25.03.0 사용. 이미지 수동 전사는 `inputs/csat_image_cells.csv`에 기록됨. 공개용 입력과 원래 묶음의 보존 파일은 행 선택 및 CSV 줄바꿈 형식이 다를 수 있음.

검증: 저장소 루트에서 `python src/preprocess/check_primary.py` 실행. 구간 합과 별도 분모 또는 원표 누계의 일치, 누락·중복·구간 경계를 검산함. 합계 검산은 시험 난도 동등성을 뜻하지 않음.
