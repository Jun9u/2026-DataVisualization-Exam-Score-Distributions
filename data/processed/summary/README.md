# 추가 요약통계 입력

2026-11-23 검증 묶음에서 선정 지표를 추출했다. 장기 변화 분석은 아직 진행하지 않았다. 평균·표준편차·과락률은 전체 점수분포나 고득점 비중을 대체하지 않는다.

- `professional.csv`: 주택관리사보 1차 2016–2025·2차 2020–2025, 세무사 1·2차 2017–2025, 관세사 1차 2016·2017·2020–2025, 2차 2020–2025 과목별 평균 및 과락 인원·비율 188행. 2016·2017년 1차는 11월 26일 직접 확보한 채점 통계 XLS의 각 연도 시트에서 추출했다. 2018·2019년 관세사, 세무사 2016년 2차와 TOEIC 2016년은 별도 보완 조사 결과가 보고되었으나 아직 이 PR에 통합하지 않았다. 과목별 응시자를 분모로 사용. 2019 세무사 1차 상법은 원표 과락률 19.40%와 인원 기준 약 20.28%의 충돌이 있어 `분석_과락률_pct` 공란 처리(평균 유지). 다른 원표와의 작은 반올림·절사 차이는 원표 및 검산 열에 보존함. 2022 세무사 행정소송법 응시자 `6.977` 표기는 6,977명으로 정제된 값 사용. 선택과목 및 세법학 면제 집단은 별도 과목 N 사용. `professional_sources.csv`는 원본별 공식 게시글과 SHA-256을 보존함.
- `toeic_annual.csv`: 국내 TOEIC L&R 정기시험 2017–2025년 공표 연평균(정수). 연간 N 미확보, 반복응시 및 제외 규칙 확인 필요. 2024년 소제목 638과 본문·도표 683이 충돌하여 683 채택. 고득점 비중은 계산하지 않음.
- `dietitian.csv`: 영양사 국가시험 2017–2025년 40–49회, 220점 만점의 공표 평균·표준편차. 2016년 이전 만점 체계 제외. 2017 두 회차 분리. 2020·2025 보고서의 과거 추이표 값으로, 각 원년 보고서와 분포 대상 정의 추가 대조 필요. 2025 보고서의 응시 N 4,935와 분포 N 4,936은 별개. 2023 회차는 본표 47회 기준.

검증: `python src/preprocess/check_summary.py`. 원자료 판독 및 기존 전체 검증은 로컬 묶음의 `code/professional.py`, `code/hwp.py`, `code/health.py`, `code/medical.py`, `code/supplement.py`, `code/rebuild.py`를 사용함. 공식 원문은 공개 저장소에서 제외함.

관세사 직접 확보 원문은 합격의법학원 게시글의 `관세사 1차 시험 채점 통계(15~17년).xls`다. 17년·16년 시트의 당해 연도 행(8·10·12·14행)과 이전 회차 표시를 구분했다. 2017년 회계학 2,793명, 과락 1,420명(50.84%); 2016년 회계학 2,826명, 과락 1,499명(53.04%). 모든 8개 과목행의 공표 비율과 재계산 비율이 반올림 범위에서 일치한다. 같은 게시글의 `관세사 1차 합격자 과목별 평균(15~17년).xls`(SHA-256 `7c3846beeacdf39ce4e49b8a16aec97e619101d3224b1e0d9fb748dd4fcb1056`)는 합격자 집단 통계이므로 전체 응시자 성적 분석에 포함하지 않는다.

주택관리사보 2차는 2020년 상대 선발 전환 이후의 6개년 자료를 사용한다(L2). 기존 보관 HWP 본문을 2026-11-26에 다시 판독해 두 과목의 평균, 응시자 수, 40점 미만 인원 12행을 대조했다. 원표에 과락률 열이 없으므로 해당 칸은 공란으로 두고, 40점 미만 인원/과목별 응시자 수로 비율을 계산했다. 2016–2019년은 이전 체계로 분리해 이번 전후 분석에서 제외한다. 원문 파일별 SHA-256과 Q-net 게시글 주소는 `professional_sources.csv`에 기록했다.
